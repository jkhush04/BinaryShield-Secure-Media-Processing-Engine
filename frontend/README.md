# BinaryShield Frontend

This frontend is a React + Vite app for the BinaryShield backend.

## Setup

1. Open a terminal in `frontend`
2. Run `npm install`
3. Run `npm run dev`

The app will start on `http://localhost:5173`.

## Requirements

- Backend must be running on `http://localhost:5000`
- The backend already allows CORS from any origin for development

## Features

- File validation via `/upload`
- Image conversion via `/images/convert`
- Video conversion via `/videos/process`
- Image-to-PDF generation via `/pdf/images-to-pdf`
